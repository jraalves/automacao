Índice dos ADRs

Cada documento tem contexto, decisão, alternativas rejeitadas, custo aceito e como medir — porque decisão sem métrica é opinião. Os arquivos são Markdown: no site publicado eles abrem como texto-fonte; com formatação, leia no repositório.

ADR 0001 — Borda com Ingress + oauth2-proxy em vez de expor o Service

Um único ponto de entrada para TLS, rate limit e cabeçalhos de segurança; a API continua ClusterIP e a allow list de tráfego vira revisão de código.

k8s/ingress.yaml · k8s/oauth2-proxy.yaml · k8s/networkpolicy.yaml

ADR 0002 — Workers desacoplados da API

Busca interativa e extração em lote têm métricas de escala diferentes: CPU para a API, profundidade de fila para o worker. Custo aceito: consistência eventual visível.

k8s/deployment-worker.yaml · k8s/hpa.yaml · k8s/pdb.yaml

ADR 0003 — Dados sintéticos publicados em vez do código original

O código não pode ser aberto; o desenho pode. Dados gerados por seed 20260124, reprodutíveis byte a byte e varridos por verificador anti-vazamento no CI.

tools/gen_data.py · tools/leak_check.py · data/AVISO-SINTETICO.md
